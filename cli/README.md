# rufus-rust 🚀

Open-source аналог **Rufus** и **DROFUS** (Android ISO 2 USB), написанный на **Rust**.

Утилита предназначена для записи образов операционных систем (ISO, IMG, RAW, DMG) на USB-флешки и SD-карты с высокой скоростью, индикатором прогресса в реальном времени, безопасным распознаванием съемных накопителей и поблочной верификацией контрольных сумм (SHA-256).

---

## ⚡ Возможности

- 🔍 **Автоматическое обнаружение дисков**: сканирует `/sys/block` (Linux), выводит названия устройств, объемы и флаги съемных носителей (`removable`), чтобы случайно не затереть системный накопитель.
- ⚡ **Высокая скорость записи**: прямой буферизованный блочный ввод-вывод (по умолчанию 4 МБ блоками) с последующим физическим `sync` на накопитель.
- 📊 **Интерактивный прогресс-бар**: расчет скорости в реальном времени (MB/s), оставшегося времени (ETA) и объема записанных данных через `indicatif`.
- 🛡 **Защита от случайной перезаписи**: обязательное подтверждение пользователя перед записью (можно отключить флагом `-y`).
- 🔒 **Верификация целостности (SHA-256)**: вычисление хеша образа и проверка первых $N$ байт целевого диска после завершения записи.

---

## 📦 Сборка и установка

Убедитесь, что установлен компилятор Rust (`cargo`):

```bash
cargo build --release
```

Исполняемый бинарный файл будет находиться в `target/release/rufus-rust`.

---

## 🛠 Примеры использования

### 1. Посмотреть доступные диски
```bash
rufus-rust list
```
Пример вывода:
```text
DEVICE          SIZE         REMOVABLE    MODEL                    
--------------------------------------------------------------------
/dev/sda        111.79 GiB   NO (system?) SBSSD120-NOV-25S         
/dev/sdc        31.25 GiB    YES          SanDisk Ultra USB 3.0    
```

### 2. Записать образ на флешку (требуются права root/sudo)
```bash
sudo ./rufus-rust flash -i ubuntu-24.04-desktop-amd64.iso -d /dev/sdc
```

### 3. Запись с поблочной верификацией хеша SHA256:
```bash
sudo ./rufus-rust flash -i archlinux.iso -d /dev/sdc --verify
```

### 4. Подсчитать SHA-256 хеш образа
```bash
rufus-rust checksum -i debian-12.iso
```

## 📱 Сборка для Android (Termux / NDK)

Так как оригинальный `com.mixapplications.rufus` (DROFUS) ориентирован на Android:
1. Вы можете скомпилировать этот инструмент в **Termux** напрямую (`pkg install rust` -> `cargo build --release`).
2. При подключении флешки через OTG кабель к Android-смартфону диск монтируется как `/dev/block/sdX` или доступен через USB OTG API.
